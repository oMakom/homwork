# Проект "Домашняя Работа 10.1"

## Описание:

Проект обработки банковских операций (Находится в стадии разработки и реализованы только несколько функций).

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/oMakom/homwork.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

Поддеживаются несколько фукций:

1. модуль masks:
   * get_mask_card_number - > принимает на вход номер карты и возвращает ее маску __XXXX XX\*\* \*\*\*\* XXXX__  
   Пример:
   ```
   7000792289606361     # входной аргумент  
   7000 79** **** 6361  # выход функции 
   ``` 
   * get_mask_account - >  принимает на вход номер счета и возвращает его маску __\*\*XXXX__  
   Пример:  
   ```
   73654108430135874305  # входной аргумент  
   **4305  # выход функции
   ```  
2. модуль processing:
   * filter_by_state - > Принимает список словарей и опционально значение для ключа state (по умолчанию 'EXECUTED').
    Возвращает новый список словарей, содержащий только те словари, у которых state соответствует указанному значению.  
   Пример: 
   ```
   # Выход функции со статусом по умолчанию 'EXECUTED'  
   [{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
   {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
     
   # Выход функции, если вторым аргументом передано 'CANCELED'  
   [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
   {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
   ```

   * sort_by_date - >  Принимает список словарей и необязательный параметр, задающий порядок сортировки 
   (по умолчанию — убывание). Функция должна возвращать новый список, отсортированный по дате.  
   
3. модуль widget:
   * mask_account_card - > обрабатывает информацию как о картах, так и о счетах. Принимает строку, содержащую тип и 
   номер карты или счета. Возвращает строку с замаскированным номером  
   Пример:
   ```
    Visa Platinum 7000792289606361  # входной аргумент  
    Visa Platinum 7000 79** **** 6361  # выход функции
   ```   
   * get_date - >  Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407". Возвращает строку с датой в
   формате "ДД.ММ.ГГГГ" ("11.03.2024"). При вводе неподдерживаемого формата, выдает ошибку.

## Тестирование:

Все тестирования проводились в пакете Tests. Для тестирования используется библиотека pytest.  
Процент покрытия кода тестами, более 80%. 
Все основные функции покрыты тестами, чтобы обеспечить корректность работы программы.  
HTML-отчеты по покрытию тестами можно найти в папке `htmlcov`
Описания тестирования по каждому модулю ниже:

### модуль masks:
* get_mask_card_number - >  Произведена проверка на буквенные значения, пустые данные, лишние пробелы и цифры в номере
* get_mask_account - > Произведена проверка на буквенные значения, пустые данные, лишние пробелы и цифры в номере
### модуль widget:
* mask_account_card - > Произведена проверка на различные значения, пустые данные, лишние пробелы
* get_date - > Произведена проверка на корректность формата данных даты на входе
### модуль processing:
* filter_by_state - > Произведена проверка на поведение с различными значениями __state__
* sort_by_date - > Произведена проверка на поведение c корректными и некорректными входными значениями даты
